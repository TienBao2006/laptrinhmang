B. run_admin.py
================================================================================
MỤC ĐÍCH:
  Entry point ứng dụng Quản trị / Chăm sóc khách hàng.
  Chạy lệnh: python run_admin.py

Luồng hoạt động:
  show_login()  →  AdminLoginWindow  →  on_login_success  →  show_admin()
                                                              ↓
                                                     root.withdraw()
                                                     CustomerCareWindow
                                                              ↓
                                                     on_close → logout → show_login()

Các hàm nội bộ (hàm lồng trong main()):
  show_login()       — Deiconify root, tạo AdminLoginWindow với callback show_admin.
  show_admin(client) — Ẩn root, tạo CustomerCareWindow với callback on_admin_close.
  on_admin_close()   — Logout, gọi show_login() qua root.after_idle.
  on_close()         — Disconnect sạch rồi destroy root khi bấm X.

  │   Kiểm tra role sau đăng nhập:                                         │
  │   • Customer / Driver  → show_booking()                                │

  │     (yêu cầu dùng run_admin.py)                                        │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def show_booking(self, client)                                          │
  │   Xóa giao diện, tạo BookingWindow với callback on_logout=show_login.  │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def _clear_root(self)                                                   │
  │   Hủy tất cả widget con của root.                                      │

  │ def on_close(self)                                                      │
  │   Ngắt kết nối mạng rồi destroy root.                                  │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def run(self)                                                           │
  │   Khởi chạy root.mainloop().                                           │
  └─────────────────────────────────────────────────────────────────────────┘
  │ def show_customer_care(self)                                            │
  │   Ẩn cửa sổ root (root.withdraw()), tạo CustomerCareWindow (Toplevel)  │
  │   cho Admin/Staff. Khi đóng CustomerCareWindow sẽ gọi                  │

  ├─────────────────────────────────────────────────────────────────────────┤
  │ def _on_care_close(self)                                                │
  │   Gọi client.logout() rồi gọi show_login() để Admin/Staff có thể      │
  │   đăng xuất và quay về màn hình đăng nhập.                             │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def _clear_root(self)                                                   │
  │   Hủy (destroy) tất cả widget con của cửa sổ root để dọn sạch trước   │
  │   khi tạo màn hình mới.                                                │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def on_close(self)                                                      │
  │   Xử lý sự kiện đóng cửa sổ: ngắt kết nối mạng an toàn rồi gọi       │
  │   root.destroy().                                                       │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def run(self)                                                           │
  │   Khởi chạy vòng lặp sự kiện Tkinter (root.mainloop()).                │

7. client/network_client.py
================================================================================
MỤC ĐÍCH:
  Lớp kết nối mạng phía client. Quản lý TCP socket, luồng lắng nghe bất đồng
  bộ, heartbeat, tự động kết nối lại và cung cấp toàn bộ API methods giao tiếp
  với server.

CLASS: NetworkClient
  ── KẾT NỐI ──────────────────────────────────────────────────────────────
  │ def __init__(self)                                                      │
  │   Khởi tạo: sock=None, send_lock, response_queue, token=None,          │
  │   user_info=None, is_connected=False, tất cả danh sách callback rỗng. │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def connect(self, host, port) → (bool, str)                             │
  │   Tạo TCP socket, settimeout(5s) để kết nối, sau đó bỏ timeout;        │
  │   khởi động _listen_loop thread và _heartbeat_loop thread.             │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def disconnect(self, clear_reconnect=True)                              │
  │   Đặt is_connected=False, đóng socket; nếu clear_reconnect thì tắt    │
  │   auto-reconnect.                                                      │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def _listen_loop(self)                                                  │
  │   Thread nền: liên tục recv_msg từ server. Nếu msg có "event" key →   │
  │   gọi callback tương ứng (seat_update/notification/user_status/        │
  │   voice_call/VOICE_UDP_PORT). Nếu không → đẩy vào response_queue.    │
  │   Khi thoát loop: gọi disconnect callbacks và khởi động auto-reconnect.│
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def _heartbeat_loop(self)                                               │
  │   Thread nền: gửi {action: HEARTBEAT} mỗi HEARTBEAT_INTERVAL giây     │
  │   (30s) để server biết client còn sống.                                │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def _start_auto_reconnect(self)                                         │
  │   Khởi động thread thử kết nối lại mỗi RECONNECT_INTERVAL giây (3s); │
  │   sau khi thành công tự đăng nhập lại nếu có user_info cũ.            │
  ├─────────────────────────────────────────────────────────────────────────┤
  │ def send_request(self, payload, timeout=8.0) → dict                     │
  │   Với send_lock: flush queue cũ, thêm token vào payload nếu có, gửi   │
  │   qua protocol.send_msg, chờ response_queue.get(timeout); trả về dict │
  │   hoặc ERROR nếu timeout/mất kết nối.                                  │

16. common/protocol.py
================================================================================
MỤC ĐÍCH:
  Giao thức Length-Prefixed TCP Framing giải quyết sticky/fragmented packets.
  Format: [4 bytes Big-Endian unsigned int = length] + [UTF-8 JSON payload].
  Thêm _SafeEncoder để tự động convert datetime → string khi serialise.

CLASS: _SafeEncoder (json.JSONEncoder)
  def default(self, obj)
    — datetime → "HH:MM:SS DD/MM/YYYY"
    — date     → "DD/MM/YYYY"
    — time     → "HH:MM:SS"
    — bytes/bytearray → hex string

HÀM NGOÀI MODULE:
  send_msg(sock, data: dict) → bool
    — json.dumps dùng _SafeEncoder, thêm 4-byte header, sock.sendall().
    — Trả về False nếu socket error (không ném exception).

  _recv_exact(sock, num_bytes) → bytes | None
    — Đọc đúng num_bytes từ TCP stream, xử lý phân mảnh gói.
    — Trả về None nếu kết nối đóng giữa chừng.

  recv_msg(sock) → dict | None
    — Đọc 4-byte header → length → _recv_exact(length) → json.loads().
    — Trả về None nếu bất kỳ bước nào thất bại.
